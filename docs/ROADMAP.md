# 🛣️ Roadmap & Future Vision

TrainFlowVision is continuously expanding to support enterprise-grade computer vision deployments. The system is built to grow from a local active learning platform into a future-ready computer vision product for drone, edge, and cloud-based ML workflows.

## Currently Completed
- [x] **PyTorch to ONNX Pipeline**
- [x] **Geotagged Drone Metadata Support**
- [x] **Teacher/Student Active Learning Workflow**
- [x] **Neural History & Rollback Mechanisms**
- [x] **Ensemble Review Mode**

## In Progress / Next Steps
- [ ] **Jetson Edge Client Integration**: Full packaging for standalone Jetson nano deployment.
- [ ] **Live RTSP Video Stream Inference**: Real-time bounding box rendering over drone video streams.
- [ ] **Autonomous MAVLink Drone Integration**: Connecting model detections directly to autonomous flight control systems.
- [ ] **Cloud Provider Agnostic Workers**: Exporting the training microservice to RunPod or AWS for distributed GPU scaling.
- [ ] **Multi-User Platform**: Role-based access, team review workflows, and dataset ownership.
